\section{Method details of the top-6 submissions}\label{app:top6}
For every phase: the shared pipeline (diagram), its common settings, and the six best finished Codabench
submissions with the settings that distinguish them.  ``Local'' is the held-out score of the same prediction:
P1 dev BERTScore F1 (200 leak-free prompts); P2 strict macro-F1 (10 held-out documents); P3 out-of-fold
macro-F1 (5 folds); P4 clean-validation macro-F1 at the tuned threshold (stacks: nested split-half); P5
cross-fitted macro-F1; P6 BERTScore F1 (300 validation documents; beam 4: 100); P7 dev micro-F1@7.
Notation: $r$ = low-rank dimension, $\alpha$ = scaling, $\tau$ = logit-adjustment strength, KD = knowledge
distillation with loss $\alpha\,\mathrm{CE}+(1-\alpha)T^2\,\mathrm{KL}$.
